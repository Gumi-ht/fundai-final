# ҰБТ Навигатор — информатикадан ҰБТ-ға дайындайтын бейімделгіш ЖИ-тренер

**AI Fundamentals · қорытынды жоба · QAIRU**

Онлайн нұсқа: `https://<сіздің-сілтемеңіз>.streamlit.app` ← деплойдан кейін ауыстырыңыз

## Не істейді?

1. **Бейімделгіш тест.** 45 сұрақтың бәрін бермейді: ЖИ-агент әр жауаптан кейін ең көп ақпарат беретін келесі сұрақты таңдайды. Әдетте 15–20 сұрақ жеткілікті.
2. **Білім картасы.** ҰБТ информатика спецификациясының 9 тақырыбы бойынша P(біледі) есептеледі, тіпті сұралмаған тақырыптар үшін де (Байес желісі арқылы).
3. **Оқу бағыты.** A* алгоритмі әлсіз тақырыптардың оңтайлы ретін табады: көп балл беретіндері ертерек, бірақ пререквизиттер бұзылмайды.
4. **ҰБТ жоспары.** «10 күн, күніне 1,5 сағат» сияқты шектеуге қарай қай тақырыптарды оқу керегін жасыту әдісі (simulated annealing) таңдайды.
5. **Жаттығу + ЖИ түсіндірмесі.** Әр жаттығу жауабынан кейін білім картасы HMM бойынша жаңарады; қате жауапқа LLM қазақша түсіндірме береді.
6. **«Ішінде не болды».** Барлық алгоритмдердің жұмысы көрінеді: ықтималдықтар, агент шешімдері, A* түйіндері, MCMC, тәжірибе графиктері.

## Агент сипаттамасы (PEAS)

| | |
|---|---|
| **P** — Performance | деңгейді дәл анықтау, сұрақ саны аз, ҰБТ балының күтілетін өсуі |
| **E** — Environment | студент (ішкі білімі жасырын, ішінара бақыланатын орта) және сұрақтар банкі |
| **A** — Actuators | келесі сұрақты таңдау, оқу бағыты мен жоспар беру |
| **S** — Sensors | жауаптың дұрыстығы және «сенімдімін / болжадым» белгісі |

## Нәтижелер (`python evaluate.py`, тест бөлігіндегі 60 студент)

Толық кесте мен графиктер — `results/metrics.md`. Қысқаша:

- **Бейімделгіш тест (expectimax)** орташа 15 сұрақпен (толық тесттің үштен бірі) әлсіз тақырыптардың **97%-ын** табады (толық 45 сұрақтық тест — 98%).
- **Expectimax агенті** кез келген сұрақ санында кездейсоқ таңдаудан дәлірек. Q-learning агенті алғашқы 10 сұрақта кездейсоқтан жақсы, бірақ expectimax-қа жетпейді: 3⁹ күйлік кестені үйренуге 20 000 эпизод аздық етеді. Бұл — шынайы нәтиже, оны қорғауда талқылауға болады.
- **Логистикалық регрессия** толық тестте 3 деңгейді дәлірек ажыратады, бірақ әр тақырыпқа көп жауап керек және сұралмаған тақырыпты бағалай алмайды. Байес желісі әлсіз тақырыпты жақсырақ табады.
- **A\*** оңтайлы бағытты UCS-пен бірдей құнмен табады, бірақ түйінді ~2,5 есе аз ашады.
- **Simulated annealing** барлық тексерілген жағдайда толық перебормен бірдей оңтайлы шешім тапты.
- **Гиббс сэмплингі** үлгі саны өскен сайын дәл posterior-ға жақындайды.

## Деректер туралы

Нақты оқушылардың деректері жоқ, сондықтан `generate_data.py` 300 жасанды студент жасайды. Олардың білім моделі `knowledge.py`-дағы модельден әдейі басқаша (параметрлері де, деңгей саны да), сондықтан бағалау «өз жауабын өзі тексеру» болмайды. 60 студент тек тексеруге қалдырылған.

Тақырыптар Ұлттық тестілеу орталығының информатика спецификациясы бойынша алынған. Сұрақтар — жоба авторлары құрастырған оқу сұрақтары.

## Іске қосу

```bash
pip install -r requirements.txt
python generate_data.py   # data/students.csv, true_levels.csv, test_students.csv
python train.py           # model.joblib
python train_rl.py        # q_table.npz, results/rl_curve.csv  (~30 с)
python evaluate.py        # results/metrics.md + графиктер
streamlit run app.py
```

Дайын `model.joblib`, `q_table.npz` және `results/` репозиторийде бар, сондықтан сайтты бірден іске қосуға болады.

**LLM түсіндірмесі (міндетті емес):** `.streamlit/secrets.toml.example` файлын қараңыз. Кілт болмаса, сайт дайын түсіндірмелерді көрсетеді.
